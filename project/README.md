# Project Overview

This project explores a Human-in-the-Loop AI system for code review. The goal is to combine AI-generated review suggestions with human feedback to improve review accuracy, reliability, and efficiency.

## Main components

- Data collection and preprocessing
- AI-based review generation
- Human reviewer feedback integration
- Evaluation and comparison with baseline methods

## Suggested folder layout

- src/: implementation of the system
- data/: raw and processed datasets
- notebooks/: experiment notebooks
- tests/: test cases
- docs/: thesis-related documentation
- reports/: outputs and visualizations
